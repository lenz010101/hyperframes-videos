# HyperFrames Videos

Proyecto HyperFrames sincronizado con GitHub.

## Flujo de trabajo
1. Editar `index.html` / `compositions/`
2. Preview local: `npx hyperframes preview --background`
3. Check: `npm run check`
4. Render local: `npm run render`
5. Commit & push a GitHub
6. Al aprobar preview, render final y copiar a `C:\Users\Admin\Desktop`
